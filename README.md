## 买之前先定三件事：用途、用户在哪、预算多少

VPS 就是一台从物理服务器上切出来的虚拟小服务器，你拿到 root 权限、独立 IP 和固定的一块 CPU、内存、硬盘资源，装什么系统、跑什么程序自己说了算。它比虚拟主机自由，比独立服务器便宜，个人建站、跑小工具、做开发测试基本都落在这一档。

**用途决定内存下限。** 跑静态博客、轻量代理、开发测试，512MB 够用，1GB 是更舒服的起点；跑 WordPress 这类动态站点、小型数据库、轻量后端，2GB 起步，4GB 更稳；多站点并行或中型数据库上 6GB、8GB；12GB 那一档留给资源密集型应用。最常见的冤枉钱是给一个每天几百 PV 的博客配 4GB 内存，多出来的部分一年也用不上几次。

**用户在哪决定机房，而且多数平台买完不能换。** 受众在中国大陆，选洛杉矶或圣何塞，线路做过国内优化的更好；受众在东亚、东南亚，香港、日本、韩国三个方向延迟最低；受众在北美，纽约、阿什本、芝加哥按城市就近；受众在欧洲，阿姆斯特丹、法国、都柏林、伦敦挑一个。机房在购买那一刻就定死了，这一条在下面讲平台差别时还会提到。

**预算决定计费周期。** 年付的单价通常比月付低一截，代价是多数商家不支持退款，付出去就收不回来。第一次买，先按月付跑一段时间再决定要不要转年付，比一上来押一年稳妥。

## VPS 购买平台之间的差别，主要在五个地方

同样标着“1 核 1G”，不同平台买到的东西差得远。把下面五项对齐，基本能判断一家值不值得下单。

**退款政策。** 这一项差异最大。RackNerd 的服务条款写明任何产品都不支持退款，也没有无理由退款保证；LightNode 提供 7 天退款；AWS Lightsail 给新用户 3 个月免费的 VPS、容器和数据库。前两家是“买了就是买了”，第三家是先免费跑三个月再决定。下单前把这条翻出来看一眼，比看价格重要。

**支付方式。** 国内用户真正要确认的是收不收支付宝。RackNerd 支持信用卡、PayPal、加密货币、支付宝、银联、银行转账；LightNode 支持 Google Pay、PayPal、支付宝和信用卡；六六云是全中文界面并支持支付宝。is*hosting 页面上列的是信用卡、借记卡、电子钱包和 BTC、LTC、ETH 等加密货币，GoDaddy 的中文页没有列支付宝。一家平台不收你手上的支付方式，配置再合适也买不成。

**交付时效。** RackNerd 付款后 5 到 15 分钟收到两封邮件，第二封标题是 “KVM VPS Login Information”，里面有 IP、root 密码和 SolusVM 面板地址；LightNode 是 1 到 2 分钟部署完成；GoDaddy 官方写的是“平均时间仅为几分钟，但也有需要 24 小时或更长时间的情况”。急着当晚把站迁完的，这一栏要提前看。

**机房与线路。** 机房数量不等于线路质量。RackNerd 有 20 个数据中心，洛杉矶 DC-02 对中国线路做过优化，但它自己也说没有 CN2 GIA 这种顶级线路；is*hosting 的香港节点放在 Equinix 数据中心，Tier 3+ 等级；六六云的做法是把线路直接写进套餐名——洛杉矶分 CN2 GIA、9929、4837、双 ISP 几条，香港走 CMI，日本有软银和原生 IP，韩国有原生 IP 和双 ISP，英国有 9929 双向优化。线路写在名字里的好处是不用猜，坏处是同机房不同线路的价格能差出一倍。

**升降级和控制面板。** RackNerd 支持随时升级、后台点一下重启生效、差价按比例补，但不支持降级，机房也不能改；is*hosting 支持随时升级或降级，资源可以单独加硬盘、加 CPU、加内存，不用换套餐；LightNode 同样可以随时升级、降级或释放。买之前想清楚会不会降配，比想清楚会不会升配更实际。

## 在平台上买一台 VPS 的六个步骤

以 WHMCS 面板的商家为例，整套流程六步走完，第一次买大概十分钟。

1. **选机房和线路。** 这一步排在套餐前面，因为机房买完不能改。多数商家的配置页第一个选项就是数据中心，同一机房如果有不同线路，价格会分开显示。
2. **按内存选套餐。** 回到第一节那张对照表，按用途挑，别按“反正贵不了多少”挑。
3. **选操作系统。** Linux 一般免费，常见选项有 Ubuntu、Debian、CentOS、AlmaLinux、Rocky Linux，新手选 Ubuntu 或 Debian，遇到问题搜得到答案。Windows 通常要加月费，几美元到十几美元不等，看版本。
4. **选计费周期。** 月付、季付、半年付、年付四档，年付单价最低但不可退。
5. **注册账号、填账单信息、选支付方式。** 第一次买要填邮箱、设密码、填账单地址。结账页选支付宝会跳转扫码，整个过程跟在国内电商下单差不多。
6. **付款后等邮件。** 以 RackNerd 为例，5 到 15 分钟内会收到两封邮件，一封是订单确认，另一封标题叫 “KVM VPS Login Information”，里面有 IP 地址、root 密码和控制面板地址。拿到这封邮件就算开通完成。Windows 用 Bitvise SSH 之类的客户端，Mac 或 Linux 直接开终端输入 `ssh root@你的IP`，密码粘贴进去（终端不显示密码，回车就行）。

## 常见问题

### 买了之后能换机房吗？

多数平台不能。RackNerd 明确写了机房在购买时定死，要换只能新开一台把数据迁过去，再取消旧的。下单那一刻选对机房，比后面想办法补救省事得多。

### 能升级或降级套餐吗？

看平台。RackNerd 支持随时升级，后台点一下重启生效，差价按比例补，但不支持降级；is*hosting 和 LightNode 都是升级降级都可以，还能单独加硬盘、加内存，不用换套餐。买之前想清楚会不会降配。

### 第一次买要不要直接上高配？

不必。先用 1GB 或 2GB 跑一段时间，发现瓶颈再升级，比一开始就买 4GB 以上划算。

### 年付一定比月付划算吗？

只在同款之间比较才成立。RackNerd 的 512MB 款是年付 $26.99，折合每月约 $2.25；1GB 款是月付 $17.99，这两者配置不同，不能拿来算“年付省了多少”。拿年付价和同款的月付价相乘对比，才是真实折扣。

### 支付方式真的会影响选择吗？

会。没有支付宝或银联，国内用户就得走信用卡或加密货币，信用卡还可能因为账单地址和风控被拒。下单前先确认结账页有你要用的方式，别等填完一堆信息才发现付不了款。
